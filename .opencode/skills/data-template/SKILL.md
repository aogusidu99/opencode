# 无数据建立模板skill

## 1. 起点与数据判断

- 输入已完成的数据库规格描述（字段名、字段类型、示例值、以及是否执行过逆透视）。

- 如果前面做了逆透视 (Unpivot/Melt)，在模板阶段需先将长表结构还原成透视数据，作为“源数据”。

- 输入为“已完成的数据库规格描述”与“当前拿到的数据”。

- 必须先判断当前数据是否已做逆透视 (Unpivot/Melt)：
  - 如果数据是长表结构（识别为：一列为维度标识、另一列为变量/期间、再一列为数值），则判定为已逆透视。

  - 如果数据是宽表结构（识别为：列头为多个期间/变量，行头为指标/科目），则判定为未逆透视。

- 若判定为已逆透视，则在模板阶段先将“长表结构”还原成“透视数据”，并以此作为源数据。

## 2. 规则不确定性处理

- 当处理规则不清楚或存在矛盾时，必须向用户提问并确认后再继续。

## 3. Excel模板建立子skill (Excel Template Creation)

根据原始数据和处理规则，构建一个规范的、自动化的 Excel 模板：

### 四大区块（工作表分类）

整个 Excel 模板的工作表 (Worksheets) 必须严格划分为四大类，并建议用三种以上不同的标签颜色区分：

1. 逻辑说明 (首个 Sheet)：自动整理并写明整个表格的数据流向、计算规则和处理逻辑说明。

2. 源数据：只存放清洗后的标准原始数据

3. 处理中间过程：保留所有公式和数据透视表，绝不能将中间步骤写死，必须保证整个数据处理逻辑链条 100% 可追溯、可审计。

4. 结果和展示图表：最终的数据汇总、KPI 呈现和可视化图表。

### 无限制扩展

公式和透视表的作用域不能限制死行数（例如应使用整列引用 `A:A` 或动态表格结构），确保后续无论向“源数据”表补充多少行新数据，后面的中间过程和结果都能自动计算并更新。
