# 数据清洗 (Data Cleaning)

数据库对数据格式要求极其严格，在处理任何表格数据前，必须确保数据的“整洁度”：

- 处理合并单元格：必须将所有合并单元格拆开，因为数据库每一行必须是独立完整的记录。拆分时，对于数值型应主动询问用户：是将原数据在拆分后的单元格中“全部复制填充”还是“平均分配”；其他类型直接全部复制填充。
- 统一字段名：表头（第一行）必须是唯一列名。如果出现重复，按顺序追加后缀（如 `-1`, `-2`）。禁止使用空格和中文字符标点，统一使用英文下划线命名法（如 `user_id`）。
- 处理空值 (NULL)：遇到空值时，必须向用户确认：这些空值是代表真正的“无数据”，还是需要用某个“默认值”或“上一行的数据”进行填充。
- 强制格式统一：检查并确保日期列绝对是标准日期格式，数值列绝对是纯数字（剔除单位等文本字符）。
- 同时保留修改前后的数据对比，并将差异部分黄色highlight
