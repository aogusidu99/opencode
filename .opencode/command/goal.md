---
description: 设定或回顾当前会话的目标，保持 AI 聚焦方向
---

根据用户的输入，执行以下操作之一：

## 1. 设定目标（无参数或传入新目标）

如果用户提供了目标描述，请：

1. 将目标拆解为具体可执行的子任务清单（3-7 项）
2. 为每个子任务标注优先级（P0/P1/P2）和预估复杂度（简单/中等/复杂）
3. 识别子任务之间的依赖关系
4. 使用 todowrite 工具记录完整的任务清单
5. 建议哪些子任务可以并行执行（使用 subagent）

输出格式：

```
🎯 会话目标: [一句话总结]

## 任务拆解

| # | 任务 | 优先级 | 复杂度 | 依赖 | 状态 |
|---|------|--------|--------|------|------|
| 1 | ...  | P0     | 简单   | -    | ⬜    |
| 2 | ...  | P0     | 中等   | #1   | ⬜    |

## 建议执行顺序
1. 先执行 #1 和 #3（无依赖，可并行）
2. 再执行 #2（依赖 #1）
```

## 2. 回顾进度（用户说 "回顾"、"进度"、"status"）

如果用户想回顾进度：

1. 读取当前 todo 列表
2. 对照已完成的工作，更新任务状态
3. 计算完成百分比
4. 指出下一步应该做什么

输出格式：

```
📊 进度回顾: X/Y 已完成 (Z%)

✅ 已完成: ...
🔄 进行中: ...
⬜ 待开始: ...

→ 下一步建议: ...
```

## 注意事项

- 目标应该是具体的、可验证的，不要太抽象
- 子任务粒度适中：太粗无法跟踪，太细增加噪声
- 如果目标涉及代码改动，每个子任务应附带验证方式（如 typecheck / test）
- 保持与项目 AGENTS.md 中 Definition of Done 标准一致
